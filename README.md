# Rock Paper Scissors Game 🎮

## About the Project
Rock Paper Scissors is a fun and interactive browser game built using HTML, CSS, and JavaScript. Players choose Rock, Paper, or Scissors and compete against the computer.

## Features
- Play against the computer
- Random computer choices
- Automatic winner detection
- Live score updates
- Win, lose, and draw messages
- Interactive user interface
- Sound effects for game actions

## Technologies Used
- HTML – Structure
- CSS – Styling and layout
- JavaScript – Game logic and functionality

## How to Play
1. Open the game in your browser.
2. Choose Rock, Paper, or Scissors.
3. The computer makes a random choice.
4. The winner is decided according to the game rules.
5. Scores update as you play.

## Game Rules
- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both choices are the same, it is a draw.

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run `index.html` in your browser or use Live Server.
